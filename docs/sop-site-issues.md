# Sample SOP: logging site issues in Forma Build

> **Sample procedure written for the GOAT demo.** It is not an official Gamuda procedure.
> Replace it with your team's real SOP before using GOAT on a project.

## Purpose

Every defect, safety observation or design query found on site is logged as an issue in
Forma Build (Autodesk Build) on the day it is found, so nothing is lost between the site
walk and the weekly progress meeting.

## When to log an issue

Log an issue for any defect in completed work, any non-conformance with the drawings or
specification, any safety observation, and any question that needs the designer to answer.
Log one issue per defect; don't bundle several defects into one issue.

## Issue type

Pick the type before anything else, because it decides who gets notified.
Site defects go under Quality, Defect. Safety observations go under Safety. Questions for
the designer go under Design, RFI.

## Title: location first

Write the title location first, then the defect, for example "Pier P12, level 2: honeycombing
on north face". Location first keeps the issue list sorted by area, so a package manager can
find every issue in their zone at a glance.

## Assignee

Assign the issue to the package manager for that area, not to the subcontractor directly.
The package manager confirms the defect and passes it on.

## Photos

Every issue needs at least one photo. The photo is the evidence: it shows the subcontractor
exactly what and where the defect is, it records the condition before rectification in case
of a dispute, and it lets the package manager close the issue without a second site walk.
Take a wide shot that shows the location and a close-up of the defect. Issues without a photo
are sent back to the person who raised them.

## Due dates and closing

Set the due date from the defect's severity: safety issues within 24 hours, quality defects
within 7 days unless the package manager agrees otherwise. Only the person who raised the
issue closes it, after checking the fix on site and attaching a photo of the rectified work.
